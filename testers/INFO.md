# 测试用例说明

本项目用一套 C 源程序做回归测试。按目录分成两类：

- **`check/`** —— 带预期输出。文件首行写 `/* EXPECT: ... */`，编译后在模拟器里真跑一遍，逐行比对输出。由 `tools/check.mjs` 驱动。
- **其余目录** —— 只要求"能编译、能跑完不崩"，用来覆盖那些输出不便于断言的场景（内存布局、栈容量等）。由 `tools/runall.mjs` 驱动。
- **`negative/`** —— 必须编译失败，用来确认诊断确实生效。

运行方式：

```
node tools/check.mjs     # 27 个带预期输出的用例
node tools/runall.mjs    # 全部用例
```

`check/` 与 `runall` 默认给两块 64 格内存（bank1、bank2），目标版本 154.3。

## check/ —— 带预期输出

### 运算与控制流

| 文件 | 覆盖内容 |
|---|---|
| `t01_arith.c` | 加减乘除取余、函数调用、整数除法 |
| `t02_loops.c` | for 累加、while 循环、volatile 阻断折叠后的循环 |
| `t06_recursion.c` | 阶乘、斐波那契、三角数——递归调用的中间值必须存活 |
| `t10_big.c` | 综合：gcd（含循环内别名）、数组求和、if/else、阶乘 |
| `t18_boolret.c` | `bool` 函数用在 if 条件里，且实参类型与形参不一致 |

### 数组

| 文件 | 覆盖内容 |
|---|---|
| `t03_array.c` | 普通内存数组：写入、常量下标读取、遍历求和 |
| `t04_constarray.c` | 常量数组折叠，以及 volatile 下标下的运行时读取 |
| `t09_encoded.c` | `array("encoded", ...)`：常量数组压成字符串，含运行时刻下标 |
| `t19_encoded200.c` | 编码数组的多位情况：base-57 拆分 + Horner 拼回 |
| `t20_encoded_same.c` | 编码数组全部元素相同：修正量还原 |
| `t21_traditional.c` | 同样的数组不加 pragma：留在内存里 |
| `m1.c` | 二维数组：双重循环填充、常量下标、按列求和 |
| `m2.c` | 二维数组 + volatile 运行时刻下标 |
| `m3.c` | 三维数组 |
| `n1.c` | 递归函数里的 `near` 数组：不得被切到两个内存块 |
| `n2.c` | 递归函数里含数组的 `near` 结构体 |

### 结构体与指针

| 文件 | 覆盖内容 |
|---|---|
| `t05_struct.c` | 结构体成员读写、整体赋值、按指针传参 |
| `t11_nested.c` | 嵌套结构体：内层赋值、整体拷贝后的独立性 |
| `t07_pointer.c` | `&x`、解引用写、指针递增后取值 |
| `t12_ptrmix.c` | 数组退化指针 + 指针算术，与 `&x` 混用 |

### 字符串

| 文件 | 覆盖内容 |
|---|---|
| `t08_string.c` | `char` 是字符串；`s[i]` 读字符 ASCII 码，含运行时刻下标 |

### 内容编号与 pragma

| 文件 | 覆盖内容 |
|---|---|
| `t22_content_ids.c` | 物品/建筑/单位的编号（v152..v159 顺序），全部编译期折叠 |
| `t23_pragma_id.c` | `#pragma id` 覆盖内置表 |
| `t24_pragma_var.c` | `#pragma var` 声明处理器变量 |
| `t26_opaque_cast.c` | 未定义的 `@名字`：允许强制转换，但不被折叠（读回来是 null） |

| `t28_pragma_id_custom.c` | 内置表里没有的名字，用声明的编号 |

## mem/ —— 内存布局

**volatile 相关**

| 文件 | 覆盖内容 |
|---|---|
| `v1.c` | 四种组合：volatile 标量、volatile 数组、指向 volatile 的指针、自身是 volatile 的指针 |
| `v2.c` | 两种指针限定符分别指向不同对象 |
| `m1.c` | volatile 数组在内存紧张时也必须留在内存（用 `filler` 占满空间） |

**结构体取地址降级**

| 文件 | 覆盖内容 |
|---|---|
| `e1.c` | 同一结构体两个实例，只有一个被取地址 |
| `d1.c` | 内层被取地址 → 外层也必须进内存 |
| `d2.c` | 没被取地址的实例仍留在寄存器 |
| `d3.c` | 三层嵌套，只取最内层的地址，最外层也要降级 |
| `d5.c` | 降级后的结构体拷贝与按指针传参 |
| `d6.c` | 只取成员地址不降级；取整体才降级 |
| `g1.c` / `g2.c` | 取地址后按指针访问 / 成员地址仍走名字指针 |

**定义本身要求内存**

| 文件 | 覆盖内容 |
|---|---|
| `e2.c` | 含数组成员的结构体：所有实例都在内存，不生成类型副本 |
| `e2a.c` / `e2b.c` | 同上，取地址与不取地址两种 |
| `s1.c` | 含数组的结构体：成员按偏移量读写 |
| `c1.c` | 结构体数组、二维数组、联合体混用 |
| `c2.c` | `near` 数组 |
| `d4.c` | 结构体数组元素与结构体指针并存 |

**递归**

| 文件 | 覆盖内容 |
|---|---|
| `r1.c` ~ `r4.c` | 递归函数里的局部数组：调用返回后局部变量必须各自独立 |
| `m2.c` | 递归 + 指向局部变量的指针 |

**名字指针的边界**

| 文件 | 覆盖内容 |
|---|---|
| `m3.c` | 指针来自数组、赋给数组：必须退回传统表示 |
| `m4.c` | 二级指针 `**pp`：两级都可以用名字表示 |

## arr/ 与 arr2/ —— 数组的编译期计算

| 文件 | 覆盖内容 |
|---|---|
| `arr/ca1.c` | 常量数组：下标与条件一起折叠 |
